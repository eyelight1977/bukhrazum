# Синтетические сценарии

Оба набора созданы с нуля и допустимы для публичного примера. Файлы — `examples/`, ожидаемые значения — отдельные JSON. Тестовые ожидаемые значения не импортируются приложением. Для обоих: договор 77/01/26-01, строка «1 этап 2026», январь 2026.

| Вход | Ожидаемый результат после необходимого подтверждения чтения |
| --- | --- |
| 01-coincidence/report.pdf + salary.xlsx, insurance.xlsx, production.docx, administration.docx | 0200=60000, 0300=18000, 0800=10000, 0900=20000, итог=108000. Все пять документальных агрегатов совпадают, пять формул КФЗ верны. 8+9=10000 подтверждается вместе; части отдельно не подтверждаются. 13+14=3000 рассчитаны, независимой детализации нет. Трудоёмкость/материальные затраты также не доказаны; итоговое заключение с оговорками при qualified-политике |
| 02-discrepancy/report.pdf + все DOCX/XLSX этого каталога | Документы дают те же 108000; в КФЗ 0800=11000, итог=109000. Разница +1000 по статье и итогу — одна группа расхождений. Арифметика КФЗ при этом верна. Копия production исключается как дубликат, other-period — февраль, other-contract — другой договор. Рекомендация вернуть на доработку |

Автотест дополнительно загружает переименованные файлы и копию КФЗ среди источников: назначение не должно зависеть от названия, сам отчёт исключается по совпадению байтового хеша. Ведомость содержит строки 0201/0202 и некэшированную формулу SUM: ожидаемая сумма получается из начислений.

Статусы до подтверждения сомнительного OCR могут быть непроверенными с конкретной причиной. Это ожидаемое поведение, а не ошибка числового сравнения. При ручном запуске сравни значение с показанным сканом и сохрани уточнение. Инструкция автотеста — в README.
