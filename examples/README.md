# Публичные синтетические примеры

Два независимых набора входных файлов с ожидаемым результатом: `01-coincidence`, `02-discrepancy`. Они не используют сканы или тексты исходного набора заказчика. Ожидаемые JSON предназначены только для проверки результата человеком/тестом и не загружаются в приложение.

Загрузи report.pdf как КФЗ, остальные DOCX/XLSX выбранного каталога как первичные и расчетные документы. Параметры и ожидаемые статусы указаны в expected.json и docs/use_cases.md. Примеры не являются реальными бухгалтерскими документами.
